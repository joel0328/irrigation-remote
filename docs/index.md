# Custom Irrigation Remote

A research and design project: a lower-cost handheld radio remote for residential irrigation, in the same job as the TRC Commander. Early stage. This site holds the research, the proposed design, and (later) firmware and hardware.

**Nothing in this project has been built or tested yet.** Pages say which claims are confirmed, documented, reported, inferred or unknown. See [research conventions](research/README.md).
